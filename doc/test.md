# テスト
本ドキュメントは、このプロジェクトが開発するTUI型テキストエディター（以下、「本ツール」）のテスト方法を記述するものです。

## テスト実行方法
以下でテストを実行します。
```bat
go test ./internal/tui
```

## テストシナリオ定義
テストの本体はテストシナリオを実行することによって実装されています。
テストシナリオは ./testdata に格納されています。
そのフォーマットは以下です。

%%
テキストボックスの幅
テキストボックスの高さ
テキストエンジン（PlainText or StyledText）
%%
命令列
%%
期待するテキスト
%%

命令列は以下のいずれかを1行づつ書き込みます。
* TYPE "書き込むテキスト" - 指定テキストを書き込みます。
* TYPELN "書き込むテキスト" - 指定テキストを書き込み、改行します。
* REMOVE_CHAR - バックスペースを押下したときの動作を実行します。
* REMOVE_SELECTION - 選択範囲を削除します。
* SELECTION_START - 選択を開始します。
* SELECTION_END - 選択を終了します。
* MOVE_LEFT - カーソルを左に動かします。
* MOVE_RIGHT - カーソルを右に動かします。
* MOVE_UP - カーソルを上に動かします。
* MOVE_DOWN - カーソルを下に動かします。
* MOVE_TEXT_START - カーソルをテキストの先頭に動かします。
* MOVE_TEXT_END - カーソルをテキストの末尾に動かします。
* MOVE_LINE_START - カーソルを行の先頭に動かします。
* MOVE_LINE_END - カーソルを行の末尾に動かします。
* FIND_PREV "検索文字列" - カーソルを指定文字の先頭に移動します。
* FIND_NEXT "検索文字列" - カーソルを指定文字の先頭に移動します。
* BYTE_POS 行位置 列位置 - 現在の編集位置が指定の位置と一致するか検証します。
* VAR "変数名" "中身" - 変数宣言を実行し、のちのテキスト一致テストでマクロとして使えるようにします。

期待するテキストは基本的には一致してほしいテキストをそのまま書きます。
カーソルによる選択状態は < と > で囲って表します。
変数宣言が既に行われている場合、変数名と一致する部分をその変数の中身で置き換えてからテキスト一致テストが行われます。
