# 仕様
本ドキュメントは、このプロジェクトが開発するTUI型テキストエディター（以下、「本ツール」）の仕様を記述するものです。

# 起動方法
本ツールはコマンドラインから起動されます。
コマンド名は `ckro` です。

必須の引数、オプションは存在しません。
コマンド名だけで起動することができます。

```bat
ckro
```

オプションにより、起動時のディレクトリを指定することができます。

```bat
ckro -d ./project
```

# 画面構成
本ツールは `Emacs` を参考にした画面構成をしています。
画面はツリー、エディター、モードライン、ミニバッファから構成されます。

## ツリー
起動時ディレクトリに存在するファイルをツリー形式で表示します。
フォーカスが当たっているとき、矢印キーによってカーソルを移動できます。
エンターを押下することでそのファイルを開くことができます。
現在開いているファイルが編集済み、未保存の場合は今のファイルを保存してから開くかユーザーに尋ねます。

ツリーは画面左側に縦長に表示されます。

## エディター
現在開いているファイルの中身を表示する領域です。またキー入力によってその内容を編集可能です。
入力領域の左側には行番号を表示するガターが存在します。
フォーカスが当たっているとき、現在カーソルが置かれている文字を反転して描画します。

本ツールの目玉機能として、リッチテキストの表示と編集を同時に扱えるという点があります。
つまり、プレビューモードというものが存在しません。
この仕様については内容が長くなるため、後述します。
※「テキストボックス」の章を参照のこと。

## モードライン
モードラインという名前は `Emacs` から借りていますが、全く同じ役割ではありません。
モードラインは読み取り専用の高さ一行のテキストボックスです。
いまのところ、ユーザーに対するメッセージを表示するための領域として使われています。

## ミニバッファ
ミニバッファという名前は `Emacs` から借りていますが、全く同じ役割ではありません。
ミニバッファは高さ一行のテキストボックスです。
ここに文字列を入力して `Enter` を押下すると、その内容がLLMに送信され、返事がエディターに書き込まれます。
LLMがMCPを通じてツールの呼び出しを要請したとき、それを承認するか拒否するかもここから送信できます。
現在のところ、LLMと対話するためだけに存在する領域です。

# フォーカス制御
どの画面であっても、Shift+Tab によってフォーカスを移動することができます。

# テキストボックス
本ツールのメイン機能であるテキスト編集機能について。
このテキストボックスはリッチテキストを扱うことできます。
`litemark` という独自のマークダウン方言に対応しており、特定の部分を太字にしたり見出しにしたりできます。
特徴的なのは、編集モードとプレビューモードに分かれていない点です。
例えば、編集した結果見出しとして認識されるテキスト部分になると、すぐに太字で表示されます。
また、このとき見出しを構成する余分なシンボルは表示されません。
（`litemark` においては見出しはシャープから始まるという規則があるが、見出しになるとシャープは非表示化）

他にも、テキストを飾り付きで表示することも可能です。
例えば、バッククォートで囲むとコードブロックとして認識されますが、この部分はボックスで囲まれて表示されます。
もちろん、この「飾り」の部分は編集不可であり、カーソルを置くこともできません。

また、アスタリスクで囲むと太字になりますが、囲まれた部分を削除するとアスタリスクも一緒に消えます。
このように、リッチテキストを扱う編集では一般的な操作を定義できないため、細かいエッジケースを場合分けで対処しています。
